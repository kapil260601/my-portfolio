# Kapil Patel - Portfolio Website

A modern, fully responsive personal portfolio website showcasing professional experience, skills, and projects.

## Features

- **Animated Hero Section** - Eye-catching introduction with dynamic typing effect
- **Smooth Navigation** - Sticky navbar with smooth scroll to sections
- **Skills Showcase** - Interactive skills display with animated progress bars
- **Experience Timeline** - Professional journey presented in a clean timeline
- **Project Gallery** - Featured projects with detailed descriptions
- **Contact Form** - Easy-to-use contact section with social links
- **Fully Responsive** - Optimized for mobile, tablet, and desktop
- **Modern Design** - Clean UI with smooth animations and transitions

## Tech Stack

- **Frontend**: React 18, TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Build Tool**: Vite
- **Deployment**: Vercel / Render

## Quick Start

### Install Dependencies
```bash
npm install
```

### Run Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

## Deployment

See [DEPLOYMENT.md](./DEPLOYMENT.md) for detailed deployment instructions to Vercel or Render.

### Quick Deploy to Vercel
```bash
npm install -g vercel
vercel
```

## Customization

All content is easily customizable:
- Personal information in `src/components/Hero.tsx` and `About.tsx`
- Skills in `src/components/Skills.tsx`
- Work experience in `src/components/Experience.tsx`
- Projects in `src/components/Projects.tsx`
- Contact details in `src/components/Contact.tsx`
